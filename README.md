# Editorial Burgundy — Lucas Villagra Torcomian

This is a static website prepared for GitHub Pages.

## Files
- `index.html`: Home page
- `research.html`: Publications and preprints
- `assets/style.css`: Shared visual design
- `assets/lucas-photo-placeholder.svg`: Temporary portrait placeholder

## Before publishing
1. Replace `assets/lucas-photo-placeholder.svg` with your photograph.
2. Name the photograph `lucas-photo.jpg` (or update the image path in `index.html`).
3. Check the publication metadata and links against your latest CV.
4. Confirm that your Google Drive CV is publicly viewable by anyone with the link.
5. Review your contact details and decide whether to display your office number.

## Publish with GitHub Pages
1. Create a public repository named `lucasvillagra.github.io` under your GitHub account (`lucasvillagra`).
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. In the repository, open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. After GitHub finishes deploying, visit `https://lucasvillagra.github.io`.

No build tools or programming knowledge are required. This is plain HTML and CSS.
